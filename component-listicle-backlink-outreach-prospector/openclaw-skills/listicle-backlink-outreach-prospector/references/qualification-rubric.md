# Qualification Rubric

Score each candidate 1-5.

## Relevance
5 = same buyer/problem/category; 3 = adjacent; 1 = unrelated.

## Authority/quality estimate
Use available provider metrics if configured. If not, infer cautiously from brand, editorial quality, indexing, traffic estimates, and spam signals. Mark confidence.

## Editorial likelihood
5 = actively updated list/resource with similar inclusions; 3 = plausible; 1 = static/news-only/no update path.

## Risk
5 = low risk/editorial; 3 = uncertain; 1 = spam/PBN/paid-link-only/irrelevant.

## Expected impact
Higher if the prospect is relevant to the target keyword/page, links to ranking competitors, and the target page is already on-page/internal-link ready.
