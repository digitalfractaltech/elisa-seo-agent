# Loop Patterns

## Ranking loop
1. baseline-rank-position-tracker / DataForSEO snapshot
2. rank-stuck-diagnostic or local-page-diagnostic
3. standard-optimizer-single or local-page-tuner if on-page issue
4. sitemap-keyword-linking-auditor / internal-link-builder if internal support issue
5. backlink-opportunity-recommender if authority issue
6. performance-tracker-reporter after measurement window

## Internal linking loop
1. site-architecture-mapper
2. sitemap-keyword-linking-auditor
3. reviewer
4. internal-link-builder-sitewide or cms-draft-implementer after approval
5. verify links
6. report

## Backlink outreach loop
1. backlink-opportunity-recommender
2. listicle-backlink-outreach-prospector
3. reviewer
4. approver approval
5. gmail-outreach-manager draft/send/check replies
6. performance-tracker-reporter

## Weekly check-in loop
1. baseline-rank-position-tracker
2. dataforseo-rank-tracker-adapter if configured
3. performance-tracker-reporter
4. decide next batch/diagnostic/monitoring action
