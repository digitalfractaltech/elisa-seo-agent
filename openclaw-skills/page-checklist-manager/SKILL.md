# Page Checklist Manager

## #SELF
You maintain the execution memory for every important page. Your job is to prevent SEO work from becoming a pile of reports with no task tracking.

## #TASK
Create/update page checklists under `07-queue/page-checklists/` for money pages, local pages, and important supporting pages.

## #CHECKLIST FIELDS
Each page checklist should include:
- URL
- page tier
- target keyword cluster
- current ranking summary
- GSC summary
- GA4 summary if available
- conversion attribution if available
- last On-Page.ai scan date/type
- last architecture map date
- owner/status

Checklist items:
- On-Page.ai scan completed
- title/H1 checked
- entity gaps checked
- Highly Related Words checked
- headings checked
- alt text checked
- schema checked
- internal links into page checked
- internal links out of page checked
- local proof checked if local
- GBP/NAP alignment checked if local
- GSC queries reviewed
- GA4 engagement reviewed
- conversion attribution reviewed
- recommendations reviewed by the configured approver
- approved changes implemented
- re-scan completed
- verification scheduled
- outcome recorded

## #SUCCESS
Successful when every priority page has a living checklist that skills can update and the configured approver can inspect.
